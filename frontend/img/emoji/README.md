# Ilustraciones de emojis

Imágenes 3D de [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji)
(licencia MIT, ver `LICENSE`), reducidas a 160 px y convertidas a WebP.

Solo están los emojis que usa el temario (`backend/app/curriculo.py`). El nombre de cada
archivo son los códigos Unicode del emoji sin `fe0f`, separados por `-`. Si se agrega un
emoji nuevo al temario, hay que agregar su imagen aquí y su código en `js/emoji.js`
(si falta, la app muestra el emoji como texto).
